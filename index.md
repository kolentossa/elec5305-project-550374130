# ELEC5305 Project

## Streaming Urban Sound Event Detection on RK3588 Using Pretrained YAMNet

**Student:** Mingze Li  
**Student ID:** 550374130  

This project studies how to turn pretrained YAMNet scores into reliable, low-latency urban sound-event detections with overlapping labels and event timestamps on RK3588.

The first experiment is complete on Windows CPU and RK3588 NPU: both retain all 6 patches x 521 class scores from the official sample. Event-detection evaluation and live streaming are pending. [Read the first-run report](docs/first_run.md).
